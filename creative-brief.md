# Creative brief (one per test ad)

Fill one in for every ad before it's designed. It keeps each test to **one message** and makes sure the designer, the copywriter and whoever replies to chats all know what the ad promises.

## Blank brief

```
Test ID:              T__
Theme:                (must match the theme name in the workbook exactly)
Hypothesis:           We think [audience] will message us more when we lead with [theme] because [reason].

Hook (first line):    
Offer:                
Proof (optional):     
Call to action:       e.g. "Message us on WhatsApp"
Pre-filled message:   e.g. "Hi! I'd like to know about the [offer]"

Visual:               
Text on image:        (max ~6 words)
Formats:              1080×1080 feed · 1080×1920 stories/reels

Audience:             (same as every other ad in this test)
Daily budget:         (same as every other ad in this test)
Dates:                start __ / end __

What the replier should say first:
Qualifying questions:
```

## Filled example

```
Test ID:              T01
Theme:                Free hardware / no upfront cost
Hypothesis:           We think independent café owners will message us more when we lead with
                      "no upfront cost" because the price of new hardware stops them switching.

Hook (first line):    Still paying thousands for POS systems? There's a better way.
Offer:                Free POS hardware when you switch this month.
Proof (optional):     [a real proof point, e.g. number of venues using it, or a short review]
Call to action:       Send message (WhatsApp)
Pre-filled message:   Hi! I'd like to know about the free hardware offer.

Visual:               Real photo of the POS on a café counter, owner smiling, morning light.
Text on image:        Free POS hardware. $0 upfront.
Formats:              1080×1080, 1080×1920

Audience:             Brisbane + 40 km, 25–65, broad
Daily budget:         ₹400
Dates:                3 Mar – 10 Mar

What the replier should say first:
  "Thanks for reaching out! Yes, the hardware is free when you switch this month.
   Can I ask two quick questions so I can tell you exactly what you'd get?"
Qualifying questions:
  1. What POS are you using now?
  2. How many terminals / staff?
  3. Do you do delivery (Uber Eats, DoorDash)?
```

## Creative tips for message ads

- **Real photos beat stock.** The product in a real business, or a real owner.
- **Big, short text on the image.** It should read on a phone at arm's length.
- **The visual should say the theme too.** A "free hardware" ad shows the hardware; a "fees" ad shows a receipt or a percentage.
- **Video:** say the hook in the first 2 seconds, and add captions.
- **Keep the creative the same across themes in a first test** where you can (same photo, different hook), so the message is the only difference. Test creative separately once you know the winning theme.
